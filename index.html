AI writes Python. Noise stripped out.

As soon as your chatbot finishes writing Rhino code, the Chrome extension detects it, strips 60+ toolbar words like "Download" or "Copy code", and places the exact clean script into the unified Manual Execution box.

Server chunks it. Rhino stays smooth.

Your local background server (server.py on 127.0.0.1:8765) breaks long scripts into syntax-safe steps (≤ 25 lines). Inside Rhino, install_plugin.py executes one step per Idle tick on the main thread — zero freezes.

Live viewport. Synced back to Chrome.

After every step (and while idle), the Rhino worker script captures the active 3D view on the main thread and uploads JPEG frames to the background server — giving you a live synced viewport, Fit, and Refresh without installing any .rhp plugin.

Manual Background Server Mode

No PluginManager. Just run the server.

Installing compiled .rhp plugins directly inside Rhino can often fail due to blocked assemblies, version mismatches, or restricted environments. Rhino Live Bridge is specifically designed to work 100% plugin-free by running a lightweight Python server manually in the background.

How this mode works: Keep server/start_server.bat (or python server.py) running in the background, and run rhino-plugin/install_plugin.py once inside Rhino via EditPythonScript (F5). Using built-in .NET WebClient, Rhino polls tasks every 500 ms, executes steps safely on the main thread, and uploads live viewport frames back to Chrome!

Complete Installation & Daily Usage Tutorial

Up and running in five simple steps.

1 / 5

Manual background-server setup & workflow:

Download the repository & install the 3 server packages.

Clone or download the project from GitHub onto your computer. Then install FastAPI, Uvicorn, and Pydantic once in your system Python (Rhino itself needs zero pip packages).

pip install fastapi uvicorn pydantic

One-time prerequisite

Standard Python 3 on Windows or macOS

Start the bridge server manually in the background.

Open the server/ folder and double-click start_server.bat (or run python server.py in a terminal). Leave this window open in the background — it hosts the local bridge on http://127.0.0.1:8765, chunks code, and caches live viewport frames.

cd server && python server.py

Keep running in background

Check http://127.0.0.1:8765/status anytime

Run install_plugin.py inside Rhino (no PluginManager).

Open Rhino 7 or Rhino 8, type EditPythonScript in the command bar, open rhino-plugin/install_plugin.py, and press F5 (Run). Leave Rhino open — the worker connects to your background server and enables both code execution and the synced live viewport.

EditPythonScript → Open rhino-plugin/install_plugin.py → Press F5

Inside Rhino 7 or Rhino 8

Re-run F5 whenever you open a fresh Rhino session

Load the unpacked Chrome extension from extension/.

Navigate to chrome://extensions in Chrome, Edge, or Brave. Enable Developer mode in the top-right corner, click Load unpacked, and select the extension/ folder from the repository.

chrome://extensions → Developer mode ON → Load unpacked (extension/)

Browser side ready
